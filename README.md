# 河南科技大学研究生课表网站

把研究生管理系统的个人课表抓下来，做成一个带节次时间、周次切换、实时倒计时的网站，
并且每天早上 07:30 把当天课表推送到企业微信群机器人。

**在线访问** → https://dailong.me/haust-timetable/

纯原生 HTML/CSS/JS + Node，**零第三方依赖**，不需要构建步骤。

---

## 功能

**课表展示**
- 周视图网格：7 天 × 12 节次，课程块按周次范围与节次跨度绝对定位
- 列表视图：按天分组的当日安排，手机上默认走这个视图
- 周次切换器 1–20 周，实际本周用橙色圆点标记
- 课程详情弹窗：课程编号、性质、学分、学时、考核方式、上课语言、主讲/任课教师、全部上课时段、课程简介

**时间**
- 每个节次都标注真实钟点（如 `14:30-16:05`），不是只给"第5-6节"
- 两套作息自动切换：第一套 5/1 起执行、第二套 10/1 起执行，按**当天日期**而非整周选取
- 顶栏实时时钟、当前周次、学期进度条
- 下一节课卡片：显示课程、时间、教室，以及"已上 X 分钟"或"距开课还有 X"
- 周视图里今天这一列高亮，并有一条橙色当前时间线

**推送**
- 企业微信群机器人 markdown 消息，含日期、周次、每节课时间/教室/教师/周次范围
- 设置面板：保存 webhook、启用开关、推送时间、无课是否提醒、测试发送、立即推送、消息预览
- webhook 不回显（只显示末 6 位），支持一键清除

**其他**：明暗主题切换、响应式、可离线用 `file://` 直接打开

## 文件说明

| 文件 | 作用 |
|---|---|
| `data.js` | 抓取到的课表数据、课程元信息、两套作息表、学期锚点。**改课表只需改这个文件** |
| `schedule-core.js` | 周次推算、作息选取、课程查询、消息生成 —— 浏览器与 Node 共用一份，保证两边显示一致 |
| `app.js` | 前端渲染与交互 |
| `index.html` / `styles.css` | 页面与样式 |
| `server.js` | 静态服务 + `/api/config` + `/api/push` + 每日定时调度 |
| `push-core.js` | Node 侧配置读写与 webhook 发送 |
| `push.js` | 命令行 `preview` / `test` / `send`，供 cron 或任务计划程序调用 |
| `Dockerfile` | 单容器部署 |
| `.github/workflows/daily-push.yml` | GitHub Actions 定时推送 |
| `DEPLOY.md` | 三种部署方式的完整说明 |

`push-config.json`（含密钥）和 `push-state.json` 已在 `.gitignore` 中，不要提交。

## 本地跑起来

```bash
git clone https://github.com/dll315/haust-timetable.git
cd haust-timetable
node server.js 5561
```

打开 http://127.0.0.1:5561/ 。默认只监听 `127.0.0.1`。

```bash
node push.js preview          # 看今天该推什么，不发送
node push.js test             # 发一条测试消息（需先配好 webhook）
```

## 部署

详见 [DEPLOY.md](DEPLOY.md)，三种方式：

| 方式 | 网页在线 | 设置可保存 | 定时推送 |
|---|---|---|---|
| 服务器直接跑 `node server.js` | ✅ | ✅ | ✅ |
| Docker 单容器 | ✅ | ✅ | ✅ |
| GitHub Pages + Actions cron | ✅ | ❌ 只读 | ✅（可能延迟） |

**为什么纯静态做不了推送**：企业微信机器人接口不返回 CORS 头，浏览器 `fetch` 只能以
`no-cors` 模式发出去但拿不到 `errcode`，无法确认是否送达。所以发送动作必须由 Node 执行。
本项目实测：GitHub 境外 runner 可正常访问 `qyapi.weixin.qq.com`。

## 数据来源与两个待确认假设

课表来自 `yjsxt.haust.edu.cn/py/page/student/grkcb.htm`，逐周（第 1–32 周）请求后按
`kcId + 星期 + 节次 + 周次范围` 去重得到全部 12 个上课时段——只抓默认视图会漏掉
晚开课的课程。抓取时间 2026-09-18，短学期与第二学期确认为空。

有两处系统查不到、由外部推断的信息，**如果和实际不符请改 `data.js`**：

1. **`semester.week1Monday = "2026-08-31"`** —— 研究生系统不提供校历，这个日期由
   "2026-09-18 是第 3 周"反推得出。若学校开学周不是这天，整张表的日子会平移。
2. **`bellSets` 的节次时间** —— 取自河南科技大学**教务处（本科口径）**公布的《作息时间》
   （`jwc.haust.edu.cn/rddh/zxsj.htm`）。研究生系统本身不含钟点信息。
   若研究生实际作息不同，直接改这两个数组。

另外注意：第 5 周（9/28–10/4）横跨 10/1 的作息切换，所以同一周内周一用第一套、
周五用第二套。左侧时间轴整周共用只能显示周一那一套，课程块内的标签才是按当天算的。
